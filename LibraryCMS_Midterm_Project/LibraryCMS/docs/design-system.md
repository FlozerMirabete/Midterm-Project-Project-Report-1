# Design System Notes

The class template specifies the shared system colors and typography below. Use these in the team's Figma prototype; this document is a checklist, not evidence that the Figma work has already been completed.

- Forest `#1F3B2C`: titles, dark surfaces, table headers
- Gold `#C9A227`: highlights and key numbers, used sparingly
- Cream `#F2F1E7`: cards and screenshot frames
- Green `#2E7D4F`: completed/success states
- Dark Gold `#9A7B12`: in-progress states
- Brick `#B5452F`: blocked/error states
- Titles: Cambria Bold; body: Calibri; API/code: Consolas
- Reuse shared sidebar/navigation, buttons, inputs, tables, and status badges from the class design system.
- Date format example: `Sep 25, 2026`; money format example: `₱1,500.00`.

Before submission, add screenshots from your actual Figma file, compare with at least two other modules, and ensure every displayed field exists in `server/openapi.yaml`.
